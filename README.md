# model-advisor-local

Советник по выбору модели Claude и доступных настроек под задачу. Сначала даёт рекомендацию, затем ждёт решения пользователя.

## Установка

Склонируйте репозиторий в отдельную папку скилла. Если такая папка уже существует, сначала сохраните свою версию; команда ниже рассчитана на новую установку.

```powershell
git clone https://github.com/smmisha/model-advisor-local.git "$HOME/.claude/skills/model-advisor-local"
```

Основной файл: [SKILL.md](SKILL.md). Сохраняйте вложенные папки вместе с ним. При необходимости откройте новую сессию приложения для обнаружения скилла.

## Использование

Укажите имя скилла в запросе и опишите задачу. В клиентах с меню скиллов выберите его через доступное меню.

## Ограничения

Это инструкции для ассистента, а не исполняемая программа. Они не переключают модель автоматически и не гарантируют результат. Доступность моделей, уровней reasoning и лимиты зависят от приложения и аккаунта; проверяйте текущие настройки. Упомянутые версии и числа не являются универсальным актуальным каталогом.

## Проверка публикации

Проверены состав файлов, структура Markdown, локальные ссылки и отсутствие машинных путей или типичных токенов доступа. Поведенческая проверка скилла в отдельной сессии не проводилась.
